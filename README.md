# Severed Signal Studios

This repository holds the studio's public GitHub profile and community files.
It is also where players report bugs in our games and send feedback.

## Report a bug

1. Search the [existing issues](https://github.com/Severed-Signal-Studios/.github/issues?q=is%3Aissue)
   in case someone has already reported it.
2. [Open a new issue](https://github.com/Severed-Signal-Studios/.github/issues/new/choose)
   and pick the form that fits.

The [accessibility statement](ACCESSIBILITY.md) says what we aim for and how to
report a barrier.

Issues and their attachments are public. Don't post personal information, and
don't report security problems here. The [security policy](SECURITY.md) explains
how to report those privately.

## Other ways to reach us

- Questions, help and conversation: [Discord](https://discord.gg/nz9bkGb2Fv)
- Anything private: [support@severedsignal.com](mailto:support@severedsignal.com)
- More detail: [SUPPORT.md](SUPPORT.md)

## What's in this repository

| Path | Purpose |
|---|---|
| `profile/README.md` | The organization's profile page |
| `.github/ISSUE_TEMPLATE/` | The issue forms for this repository |
| `SECURITY.md`, `SUPPORT.md`, `CODE_OF_CONDUCT.md`, `ACCESSIBILITY.md`, `CONTRIBUTING.md` | Policies that apply across the organization |
| `LICENSE` | The license for reusing these files. [License](#license) says what it covers. |
| `assets/` | The logo and image the profile page uses |
| `CHANGELOG.md` | Notable changes to this repository, by version. It says what the version number covers. A pull request with a notable change adds the next version. |
| `.github/workflows/tag.yml` | Tags `main` with the changelog's newest version |

GitHub also uses these policies as defaults for the organization's other
repositories.
