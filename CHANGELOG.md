# Changelog

All notable changes to this repository are documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/). There are no version numbers. GitHub shows what is on `main`, so each section is the date changes reached it, newest first.

## 2026-11-06

### Added

- The organization's profile page, `profile/README.md`. It introduces the studio and *Unaccounted*, links the website, the Steam store page and the studio's social accounts, and says where to report bugs, accessibility barriers and security problems and where to get help.
- The round studio logo, `assets/profile.svg`, with colors for light and dark mode, and the *Unaccounted* corridor screenshot that the profile page shows.
- `SECURITY.md`, which explains how to report security problems in *Unaccounted*, severedsignal.com and the studio's GitHub accounts and repositories privately, by email or through a GitHub private report. It also says what counts as a security problem and offers safe harbor for good-faith research that follows the policy.
- `SUPPORT.md`, which says where to ask for help and where the game keeps its logs, saves and settings on Windows, macOS, Linux and Steam Deck, including under Proton or Wine. It also lists what to check before you attach files to a public issue.
- `CODE_OF_CONDUCT.md`. The studio follows the Contributor Covenant 3.0 in its GitHub organization, on its Discord server and wherever someone represents the studio. To report a concern, email support@severedsignal.com or message a Discord moderator.
- Issue forms for bug reports, accessibility barriers and feedback or ideas. By sharing an idea through the feedback form, you agree the studio may use it in its games without payment or credit.
- Blank issues are turned off. The new issue page links to Discord and to private contact by email.
- `README.md`, which explains what this repository is for, how to report a bug and what each path holds. GitHub also uses `SECURITY.md`, `SUPPORT.md` and `CODE_OF_CONDUCT.md` here as the defaults for the organization's other repositories.
