# Changelog

All notable changes to this repository are documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/2.0.0/), and this repository follows [Semantic Versioning](https://semver.org/spec/v2.0.0.html). GitHub shows what is on `main`, so each merge with a notable change is a new version, dated the day it reached `main`, and Unreleased stays empty.

The version number covers what people and the organization's other repositories rely on: the paths of the policies and the profile page, the issue forms, what the policies promise, and what the license allows.

- Major: a policy, a form or the profile page moves or goes away, a policy withdraws something it promised, or the license allows less. The entry starts with **Breaking:**.
- Minor: anything else added, changed, removed or secured.
- Patch: fixes only.

## [1.0.0] - 2026-11-14

### Added

- The organization's profile page, `profile/README.md`. It introduces the studio and *Unaccounted*, a whodunit built on classic detective work, and links the website, the Steam store page and the studio's social accounts. It says where to report bugs, accessibility barriers and security problems and where to get help, and links the accessibility statement.
- The round studio logo, `assets/profile.svg`, with colors for light and dark mode, and the *Unaccounted* corridor screenshot that the profile page shows.
- `README.md`, which explains what this repository is for, how to report a bug, what each path holds and what the license covers.
- `LICENSE`, the MIT License. Anyone may copy and adapt the policies, issue forms and other text in this repository if they keep the copyright notice and the license text. The images in `assets/` stay © Severed Signal Studios with all rights reserved, and the license gives no right to the names and logos of the studio and its games. What people post in issues stays theirs.
- `SECURITY.md`, which explains how to report security problems in the studio's games, severedsignal.com and its GitHub accounts and repositories privately, by email or through a GitHub private report. It says what counts as a security problem and offers safe harbor for good-faith research that follows the policy.
- `SUPPORT.md`, which says where to ask for help and how to report a bug or barrier by email or on Discord without a GitHub account. It shows where *Unaccounted* keeps its logs, saves and settings on Windows, macOS, Linux and Steam Deck, including under Proton or Wine, under a heading for each system, and lists what to check before you attach files to a public issue. The same guide is on the website, at [severedsignal.com/support](https://severedsignal.com/support).
- `CODE_OF_CONDUCT.md`. The studio follows the Contributor Covenant 3.0 in every community space it runs, including its GitHub organization and Discord server, and wherever someone represents the studio. To report a concern, email support@severedsignal.com or message a Discord moderator. A concern about someone at the studio can also go to the platform where it happened or, at an event, to its organizers.
- `ACCESSIBILITY.md`, the studio's accessibility statement for its website and video games. It says how the studio builds and checks for accessibility, what *Unaccounted* aims to offer for controls, seeing, hearing, motion, time and screen readers, and what the website works with. It explains how to report a barrier, which barriers the studio works on first and what happens next, and links the public list of accessibility issues.
- `CONTRIBUTING.md`, which says how to report a bug, an accessibility barrier, an idea or a mistake in the studio's policies, with or without a GitHub account, and where security problems and conduct concerns go. GitHub links it when someone opens an issue.
- Issue forms for bug reports, accessibility barriers and feedback or ideas. The accessibility form covers the games and the website, labels each report `accessibility`, and offers email for anything private. By sharing an idea through the feedback form, you agree the studio may use it in its games without payment or credit.
- Blank issues are turned off. The new issue page links to Discord and to private contact by email.
- GitHub uses `SECURITY.md`, `SUPPORT.md`, `CODE_OF_CONDUCT.md`, `ACCESSIBILITY.md` and `CONTRIBUTING.md` as the defaults for the organization's other repositories.
